## 四、 评价指标

1. Accuracy：即分类正确的样本数量占全部测试样本数量的比例。
2. Macro-F1：分别计算每一个类别的 F1 Score，然后对所有类别的 F1 进行平均。对于类别分布可能不均衡的文本分类任务，Macro-F1 可以更加全面地反映模型在不同类别上的分类能力。

## 五、Task 1：Bag of Words（30 分）

使用三种 Bag-of-Words 文本表示方法训练文本分类器。本部分统一使用 Logistic Regression 作为分类模型。对于三种方法，均需要在 NYT Test Set 上报告 Accuracy 和 Macro-F1。

1. Binary Bag of Words

   首先构建词表（Vocabulary）。假设整个训练语料的词表大小为 |V|，则每一篇文档被表示为一个 |V| 维向量。对于词表中的第 i 个单词：

   xᵢ = 1（若该词出现在文档中）；否则 xᵢ = 0

   也就是说，本方法只考虑一个单词是否出现，而不考虑它出现了多少次。进行文本分词时，可以考虑使用：

   from nltk import word_tokenize

2. Word Frequency

   仍然使用词表中的所有单词构建文档向量，但与 Binary Bag of Words 不同，本方法记录每个单词在当前文档中的出现次数（Word Frequency）。

   apple apple banana
   apple  = 2
   banana = 1
   x = (c₁, c₂, ..., c|V|)

   其中 cᵢ 表示词表中第 i 个词在当前文档中的出现次数。

## 六、Task 2：Word2Vec（50 分）

本部分使用基于 Word Embedding 的方式表示文档。统一使用 100-dimensional word vectors（100 维词向量），分类器仍然使用 Logistic Regression。需要完成以下三组实验，并在 NYT Test Set 上报告 Accuracy 和 Macro-F1。

1. Pre-trained GloVe

   使用公开的预训练 GloVe Embedding（glove.6B），并选择 100-dimensional GloVe word vectors 作为单词表示。

   http://nlp.stanford.edu/data/glove.6B.zip

   对于一篇包含 n 个有效单词的文档，假设对应词向量为 e(w₁), e(w₂), ..., e(wₙ)，则文档向量通过所有词向量的平均得到：

   e(d) = (1 / n) × Σᵢ₌₁ⁿ e(wᵢ)

   最后使用得到的文档向量训练 Logistic Regression 分类器。

2. Word2Vec Trained on AG News

   使用 AG News 的文本数据自行训练一个 100-dimensional Word2Vec Model。可以使用 gensim 等工具完成 Word2Vec 训练。得到词向量之后，对每一篇 NYT 文档：

   1.  对文本进行分词；
   2.  找到每一个单词对应的 Word2Vec Embedding；
   3.  对文档内所有有效单词的 Embedding 取平均；
   4.  得到一个 100 维文档向量；
   5.  使用 Logistic Regression 完成分类。

3. Word2Vec Trained on NYT

   使用 NYT 文本数据训练 100-dimensional Word2Vec Model。随后使用同样的方法计算文档表示，再使用 Logistic Regression 训练分类器。
